# MGLabs Eaglercraft Hub

Added a dedicated, polished Eaglercraft reference area to MGLabs.

Included entries:
- EaglercraftX 1.8.8 Offline — described as the most stable/widely deployed version in the supplied copy.
- Eaglercraft 1.12.2 Offline — newer and still under development; supplied copy notes WASM-GC performance is better than JS.
- Original Eaglercraft 1.5.2 Offline — classic older version, explicitly described as having older graphics/features than 1.8.8 and 1.12.2.
- EaglerXServer — server integration description for Spigot, BungeeCord, and Velocity.

The offline client archives are **not bundled** into the public MGLabs package. Download controls are intentionally informational/disabled until a distribution source the owner is permitted to publish is configured.
