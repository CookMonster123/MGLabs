# MGLabs Game Design Notes

This package includes original MGLabs game concepts inspired by broad genres such as:
- voxel crafting/survival
- endless runners
- parkour
- arcade racing
- kart racing
- vehicle soccer
- farming
- raft survival
- open-city driving
- obstacle-course platformers
- creature collection
- management sims

The games intentionally use original names, original UI concepts, and original feature combinations.

Do not copy copyrighted characters, logos, music, maps, textures, exact levels, proprietary source code, or trade dress from commercial games.

For open-source code references, check the license before reusing code or assets.
