# LifePath — MGLabs Original Life Simulator

LifePath is an original browser-based, choice-driven life simulator built for MGLabs.

## Research direction
BitLife's official website describes the game as a text-based life simulator centered on player choices, careers, relationships, money, unexpected events, and consequences. MGLabs uses those broad genre ideas only as inspiration.

## What makes LifePath original
- Original source code
- Original event writing
- Original MGLabs visual design
- Different stat model: health, happiness, smarts, social, money, energy
- School-friendly tone
- Age-stage event pools
- Education and career progression
- Relationship state
- Achievements
- Life score
- Local browser save
- Separate offline HTML edition

LifePath does not include BitLife artwork, code, characters, interface assets, proprietary event text, or branding.
