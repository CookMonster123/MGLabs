## Important
A public GitHub repository is not automatically free to copy.

Before placing a third-party game's files directly inside MGLabs:
1. Confirm the repository license.
2. Confirm image, audio, font, model, texture, and other asset licenses.
3. Preserve required LICENSE / NOTICE / attribution files.
4. Do not imply MGLabs created the third-party game.
5. Keep third-party games isolated in a `third_party/` folder when actually vendored.
