# MGLabs Remix Vault — research notes

The 20 games in Remix Vault are original MGLabs implementations. Public GitHub projects were used only as high-level research references; third-party commercial assets were not copied into the remakes.

Notable public references found during research:

- Subway Surfers-style: SahilPanhotra/subway-surfer-clone — browser 3D endless runner, states that art/code are original and procedural.
- Subway Surfers-style: JuanGr95/Subway-Surfers-Clon — Unity/C# mechanics prototype, MIT repository.
- Crossy Road-style: EvanBacon/Expo-Crossy-Road — MIT source code with separate dependency licenses.
- Geometry Dash-style: MoserLukas2004/geometry-dash-clone — browser clone, MIT repository.
- Geometry Dash-style: jonathanleahy/geometry-dash — HTML5 Canvas browser implementation, MIT.
- 2048: gabrielecirulli/2048 — MIT repository.
- Snake: patorjk/JavaScript-Snake — MIT search result.
- Tetris-style: jakesgordon/javascript-tetris — MIT search result.
- Doodle Jump-style: takosenpai2687/doodle-jump — MIT search result.
- Fruit-slicing style: an1kens/fruit-blade — MIT search result.

MGLabs does not bundle those repositories here. The playable Remix Vault titles were written as original lightweight versions to avoid republishing third-party assets or ambiguous game data.
