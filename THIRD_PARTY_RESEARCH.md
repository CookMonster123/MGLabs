# Third-party game research

## Subway Surfers WebGL repository

Repository: RohanChacko/Subway-Surfers

The repository contains an MIT license for its software. The MIT notice requires the copyright and permission notice to remain with copies/substantial portions.

However, the repository also contains image/music assets with names such as player, police, train, coin, background music, etc. The repository page does not establish that all of those assets are original or separately licensed. Because of that uncertainty, this MGLabs package does **not** redistribute those assets.

MGLabs instead includes `Metro Rush`, an original endless-runner implementation using original shapes/UI and the general lane-runner genre.

## Eaglercraft

Public Eaglercraft forks show a Creative Commons Attribution-NonCommercial 4.0 license, but Eaglercraft describes itself as a browser version of Minecraft 1.5.2. Because Minecraft code/assets and branding have separate rights, this package does not redistribute Eaglercraft.

MGLabs instead includes `Voxel Frontier: Build Mode`, an original lightweight block-building sandbox.

## Rule for future integrations

Only bundle third-party code/assets when:
1. the exact license permits redistribution,
2. required notices are included,
3. asset licensing is also clear,
4. trademarks/branding are not misrepresented,
5. private/proprietary code is not copied.
