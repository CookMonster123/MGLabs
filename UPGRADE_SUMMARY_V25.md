# MGLabs Version 25 — Fourth & Pixel

Added an original retro-style American football project called **Fourth & Pixel**.

- New `/gridiron` route and navigation item
- Playable MGLabs-integrated football game
- Run / quick pass / deep pass / field goal / punt
- Four quarters, CPU drives, scoring, downs and field position
- Difficulty levels
- Week/season record, energy, fan support and local saves
- Self-contained offline HTML edition
- Original branding and fictional presentation
- Clear non-affiliation notice; no Retro Bowl code/assets are bundled
- App catalog entry and Launchpad integration
- Package version updated to 25.0.0
