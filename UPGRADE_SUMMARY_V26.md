# MGLabs Version 26 — LifePath

Added a new MGLabs Original section: **LifePath**.

Features:
- Choice-driven year-by-year life simulation
- Childhood, school, teen, early-adult, career, midlife, and legacy stages
- Education paths
- Career progression
- Relationships
- Health, happiness, smarts, social, money, and energy stats
- Randomized outcomes
- Local save
- Achievements and life score
- Responsive UI
- Standalone offline edition at `public/lifepath-offline.html`

The project remains an original MGLabs game and does not bundle BitLife.
