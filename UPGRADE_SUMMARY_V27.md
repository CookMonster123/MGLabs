# MGLabs Version 27 — Remix Vault

Added a new Remix Vault with 20 playable original browser games inspired by popular game genres.

Every title has its own standalone HTML launch page and uses original MGLabs code/visuals. Famous titles are referenced only as genre inspiration.

Games: Metro Dash, Sky Hop, Merge Grid, Neon Snake, Block Drop, Maze Munch, Mine Grid, Word Five, Brick Burst, Galaxy Guard, Desert Sprint, Street Hop, Pulse Jump, Cloud Climb, Slice Storm, Sling Siege, Tower Stack, Spiral Drop, Chroma Hop, Temple Dash.
