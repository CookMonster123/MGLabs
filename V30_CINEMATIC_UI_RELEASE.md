# MGLabs v30 — Cinematic UI

This release rebuilds the real MGLabs dashboard to closely match the approved cinematic v30 mockup.

## Visual changes
- Scenic sakura sunset background derived from the approved v30 design reference.
- Frosted dark glass cards with pink/purple/blue glow accents.
- Compact top navigation with centered universal search.
- Student profile controls in the top-right.
- Large greeting hero and Focus Mode card.
- Four summary cards: Today's Focus, Upcoming, Recent Activity, Copilot.
- Horizontal Your Tools shelf.
- Dashboard panels for Today at a Glance, Progress, Quick Create, Themes.
- Workspace preset, Daily Motivation, and System Status cards.
- Responsive mobile layout.

## Functionality preserved
- BrightPath
- CodeCoach
- ProjectForge
- School Tools
- Portfolio
- CareerQuest
- Device Lab
- Creative Lab
- Community
- Labs Store
- Copilot panel
- Focus Mode
- Quick Create
- Animated themes
- Cloudflare Workers AI deployment
