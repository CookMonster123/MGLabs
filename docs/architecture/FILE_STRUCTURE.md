# MGLabs File Structure

## Root
- package.json — dependencies/scripts
- index.html — Vite entry HTML
- vite.config.ts — build config
- tsconfig.json — TypeScript config
- README.md — project overview
- HOW_TO_UPLOAD_TO_GITHUB.md — upload instructions

## src
- App.tsx — current application shell
- main.tsx — React entry
- styles.css — global styles
- pages/ — future page modules
- components/ — reusable UI/game components
- data/ — catalogs and idea banks
- features/ — feature-specific code
- lib/ — helpers
- types/ — TypeScript types

## docs
- ideas/ — categorized backlog
- architecture/ — structure/build plans
- games/ — game roadmap
- apps/ — app-by-app roadmaps

## third_party
- licenses/ — put required third-party licenses here when code is actually vendored
