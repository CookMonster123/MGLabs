# MGLabs Master Plan v12

## 1. Core Platform
Dashboard, launchpad, global search, favorites, recent activity, themes, accessibility, command palette, workspace presets.

## 2. Arcade
Featured games, recent games, favorites, new games, Retro Vault, open-source games, MGLabs Originals, categories, game detail pages, fullscreen and achievements.

## 3. Retro Vault
Kart racing, retro racing, classic arcade, old browser/Flash-style games, sports, platformers, puzzles, RPGs and license/source metadata.

## 4. Classic Arcade
High scores, difficulty, daily challenge, random game and local statistics.

## 5. Web Classics
Tower defense, bike stunts, physics launchers, parking, typing racers, tycoons, farms, clickers, puzzle and browser-era experiences.

## 6. Sports Arcade
Soccer, American football, basketball, baseball, hockey, tennis, golf, bowling, volleyball, skating, BMX, track, cricket and rugby.

## 7. MGLabs Originals
Metro Rush, Voxel Frontier and future original games with clear Built / Prototype / Planned status.

## 8. BrightPath
Tutor modes, subjects, mastery, study planning, practice, flashcards, exam review and accessibility controls.

## 9. CodeCoach
Editors, debugging, test cases, visualizers, snippets, challenges and language labs.

## 10. ProjectForge
Kanban, milestones, risks, MVP planning, feedback, release history and special project modes.

## 11. Device Lab
Telemetry, thresholds, replay, experiments, derived metrics, CSV, scenario presets and hardware architecture.

## 12. Community
Channels, showcases, challenges, reactions, feedback, moderation and reporting.

## 13. CareerQuest
Career exploration, skill mapping, opportunities, programs, applications and interview preparation.

## 14. PortfolioBuilder
About, projects, skills, experience, awards, education and project case studies.

## 15. School Tools
Assignments, exams, study planning, notes, flashcards, rubrics, AP review and research tracking.

## 16. Creative Lab
Branding, posters, presentations, thumbnails, scripts, wireframes, storyboards and content planning.

## 17. Labs Store
Catalog pages with versions, What's New, permissions, privacy, related apps and open buttons.

## 18. Public/Open-Source Game Integration
Structured metadata, credits, source URLs, license labels, status and platform support.

## 19. Game Importer
Choose ZIP → Build → Preview → Publish, with real validation and license preservation.

## 20. Game Detail Pages
Play, fullscreen, favorite, about, controls, developer, source, license, stats, related games and credits.

## 21. Achievements
Local-first achievements across games, BrightPath, coding, projects and Device Lab.

## 22. Global Search
Search apps, games, projects, subjects, tools, community and settings.

## 23. Developer Mode
Catalogs, feature flags, architecture, build info, credits, templates and developer documentation.

## 24. File Structure
Modular pages, games, apps, AI, hardware, projects, career, portfolio, components, hooks, lib, data, types, styles, third-party licenses and tests.

## 25. Build Order
1. Structure
2. Arcade
3. Learning
4. Creation
5. Engineering
6. Community
7. Careers
8. Polish
9. Expansion

Every major feature must use one of four labels:
- Built
- Prototype
- Planned
- External/Open-Source
