# MGLabs Game Integration Rules

## Game statuses
- Built: included directly in MGLabs.
- External/Open-Source: source project is linked and may be integrated only when its exact license and asset rights permit.
- External/Official: official commercial game/publisher link only.
- External/License-Check: source is discoverable, but redistribution is not allowed until license and asset provenance are verified.

## Retro Bowl
Retro Bowl is a commercial title by New Star Games. MGLabs can list and link to the official publisher, but should not copy, mirror, unlock, iframe around access restrictions, or redistribute the commercial game without permission.

## Eaglercraft
Do not bundle or mirror Eaglercraft in MGLabs. GitHub's DMCA repository contains Mojang complaints concerning Eaglercraft. MGLabs should not be used to bypass Minecraft authentication, school/network blocks, copyright controls, or other access restrictions.

## Safe voxel alternatives
Prefer projects with clear open-source terms and original/reusable assets. Current research candidates include:
- Voxelcraft (MIT)
- Minecraft-Like Voxel Game (MIT)
- BLK Game (open-source project; preserve notices)
- Voxel Game JS (source link only until license verification)
- Minicraft (source link only until license verification)

## General rule
Public availability is not the same as permission to redistribute. Preserve LICENSE, NOTICE, credits, and separate asset licenses.
