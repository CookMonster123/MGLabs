# Upload Checklist

Before uploading:
- Extract the ZIP.
- Upload the contents of the extracted folder, not just the ZIP.
- Make sure .github, src, public, package.json, and index.html are at repository root.

After uploading:
- Confirm the default branch is main.
- Open Actions and verify Quality Checks.
- Open Settings → Pages and select GitHub Actions.
- Wait for Deploy MGLabs to GitHub Pages.
- Test the Pages URL on desktop and mobile.
