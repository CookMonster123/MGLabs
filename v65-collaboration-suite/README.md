# v65 — Collaboration Suite

Category: Collaboration

Unified collaboration dashboard for spaces, teams, classrooms, activity, and permissions.

## Files in this module
- `Feature.tsx` — working React UI
- `service.ts` — local persistence, create/export logic
- `model.ts` — typed data model
- `hooks.ts` — React state + computed stats
- `metadata.ts` — registry metadata
- `styles.css` — module-specific styling
- `defaults.json` — version-specific defaults

This folder is inherited by all later versions.
